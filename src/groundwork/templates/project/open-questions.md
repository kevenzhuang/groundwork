# Open questions

Questions that nobody has answered yet. Each one is routed to the person most
likely to know. Add entries to the front-matter list using this shape:

```yaml
  - id: Q1
    question: "..."
    asked_by: <principal-id>
    routed_to: <principal-id>
    date: YYYY-MM-DD
    status: open        # open | answered | dropped
    answer_ref:         # pointer, e.g. repo:decisions/0003-....md
```
